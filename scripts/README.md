# Scripts

Tool scripts are built from tickets, like any other feature.

| Script | Purpose | Spec |
|---|---|---|
| `scripts/stories-to-issues.sh` | Push approved stories from `docs/backlog/draft-*.md` to GitHub Issues without creating duplicates (matches on the Story ID) | `.opencode/skills/stories/SKILL.md` |
| `scripts/impressions/` (Python) | `add`, `generate`, `review` and `search` for the impressions library | `.opencode/skills/impressions/SKILL.md` |
