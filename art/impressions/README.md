# Impressions

The reference pool for Emberwright's art. See [docs/ART_DIRECTION.md](../../docs/ART_DIRECTION.md) for the record format and rules.

- `items/` holds the image files. They are stored in Git LFS.
- `index.jsonl` has one JSON record per impression.

Only your own work, licensed work or approved generated images go here. Never add art from other games.
